# Order Tracking — Android App (SMD coursework)

An Android app for tracking product orders through three stages, **New Orders, Scheduled and Delivered**, shown as swipeable tabs. Orders are stored locally in SQLite.

## Features
- Tab layout with ViewPager: New Order, Schedule and Delivered fragments
- Add a product through a dialog
- Product list with a custom adapter
- Local storage with an SQLite helper (`ProductDB`)

## Tech
Java · XML · Fragments · ViewPager · SQLite · Android Studio

## Run
Open in Android Studio, sync Gradle, and run on an emulator or device.
